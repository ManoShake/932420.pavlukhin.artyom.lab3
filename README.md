# Лабораторная работа №3. Тема "Техногик и обзорщик гаджетов" (вариант 12).

Адаптивная вёрстка персональной веб-страницы вымышленного техноблогера Громанцева Григория с помощью
**Flexbox** и **CSS Grid**, выполненная в рамках лабораторной работы по предмету "Web-технологии".

## Краткое описание мини-проекта
Страница "О себе" сверстана на **HTML5**, оформлена в стиле "**Хай-тек**" с помощью **CSS**.
Страница содержит в себе:
* Горизонтальное адаптивное меню навигации по разделам;
* Краткую информацию "О себе", с портретом человека и карточками навыков;
* Раздел "Гаджеты недели" — карточки на Flexbox;
* Раздел "Сравнение характеристик" — дашборд на CSS Grid;
* Раздел с опубликованными обзорами;
* Форму обратной связи.

## Структура проекта
* `index.html` — разметка страницы;
* `css/style.css` — все стили и медиа-запросы;
* `files/` — аватар и иллюстрации гаджетов (SVG-заглушки).

## Изменения
* Меню `<nav>` построено на Flexbox: `flex-wrap` и `gap`, на мобильных (до 599px) пункты выстраиваются в столбец;
* Раздел "Гаджеты недели": 4 карточки `<article>` (фото, название, ключевая фишка) на Flexbox, `flex-wrap` и `flex-basis` — **1 колонка на мобильных, 2 на планшетах, 4 на десктопе**;
* Раздел "Сравнение характеристик": Grid-дашборд из 3 блоков (процессор, экран, батарея) — **1 колонка на мобильных, 2 на планшетах, 3 на десктопе**; пары "устройство — значение" оформлены через `<dl>`;
* Числовые значения характеристик обёрнуты в `<data value="...">` с машиночитаемым числом;
* Медиа-запросы: до 599px (мобильные), от 600px (планшеты), от 1024px (десктоп);
* Горизонтальной прокрутки нет: изображения имеют `max-width: 100%`, ширина контента ограничена `max-width: 1200px`;
* Контрастность текста — не ниже 4.5:1 (проверено расчётом по формуле WCAG);
* Добавлены `<meta name="description">`, `aria-label` у меню, `aria-labelledby` у секций, `alt` с описанием у изображений;
* Фото гаджетов заменены JPEG-иллюстрациями, которые находятся в каталоге `files/`;
* Исправлены замечания к лабораторной работе №2.
